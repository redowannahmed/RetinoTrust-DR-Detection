# RetinoTrust-DR-Detection

## Overview
RetinoTrust-DR-Detection is a machine learning project that leverages deep learning to automatically detect and classify diabetic retinopathy (DR) from retinal fundus images. The system aims to assist healthcare professionals in early diagnosis of this leading cause of vision loss.

## Project Objectives
- Automated classification of diabetic retinopathy severity stages
- High-accuracy detection from retinal fundus images
- Efficient preprocessing and model inference pipeline
- Comprehensive performance evaluation and documentation

## Technology Stack
- **Deep Learning Framework**: PyTorch, torchvision
- **Computer Vision**: OpenCV
- **Machine Learning**: scikit-learn
- **Data Processing**: NumPy, Pandas
- **Visualization**: Matplotlib
